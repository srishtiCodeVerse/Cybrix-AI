# 🛡️ CYBRIX AI

### AI-Powered Cybersecurity Platform

CYBRIX AI is a full-stack cybersecurity platform designed to help users analyze website security, monitor vulnerabilities, manage scan history, and interact with an AI-powered cybersecurity assistant.

---

## 🚀 Features

- 🔐 User Authentication
- 🤖 AI Cybersecurity Assistant
- 🌐 Website Vulnerability Scanner
- 🛡️ Security Header Analysis
- 🔒 HTTPS Security Check
- ⚡ Website Response Time Analysis
- 📊 Security Score
- 📜 Scan History
- 📄 PDF Security Reports
- 📈 Security Dashboard
- 🎨 Modern Cybersecurity UI
